# ЮЦ «Фаворит» — обновлённая версия лендинга

## Что внутри

- `index.html` — новый одностраничный сайт.
- `styles.css` — дизайн, сетки, планшетная и мобильная адаптация.
- `script.js` — мобильное меню, анкета на 5 вопросов, модальное окно и клиентская валидация заявок.
- `assets/logo.svg` — стилизованный логотип-заглушка по мотивам оригинала; **перед публикацией рекомендуется заменить на официальный оригинал**.
- `assets/hero-fallback.svg` — резервная иллюстрация, если оригинальное изображение с Tilda CDN недоступно.
- `privacy.html` — **черновик** информационной страницы; требует утверждения юридической политики.

## Исходный сайт и конкурентные ориентиры

Исследованы: `http://favorit-bankrot.online/`, доступная версия того же сайта `https://favorit-bankrot.ru/`, а также примеры `https://rassvet.pro/`, `https://bankrotconsult.ru/`, `https://aristokrat.group/` и `https://mfckv.ru/`.

Сохранены: бежево-золотая палитра, спокойная подача, логика первого экрана с портретом справа, основные предложения, номер, московский адрес, интерактивная анкета, шесть именованных клиентских историй и реквизиты организации.

Внедрены: понятный заголовок и позиционирование, единая ведущая кнопка «Рассчитать стоимость», блок конкретных преимуществ, интуитивная 5-шаговая анкета, видимый прогресс и возможность вернуться назад, отдельное пояснение рисков, структурированный процесс работы, FAQ, мобильное меню, мобильная панель CTA, быстрый звонок, доступная модальная форма, SEO-метаинформация и базовая доступность.

## ОБЯЗАТЕЛЬНО перед публикацией

1. **Подключить обработчик заявок.** По умолчанию формы работают как демонстрация: они НЕ пересылают и НЕ сохраняют персональные данные. В `index.html` *перед* подключением `script.js` установить `window.FAVORIT_LEAD_ENDPOINT = '/api/leads';` и настроить на сервере защищённый HTTPS API с приёмом JSON, CRM/почтой, логами и защитой от спама. Протестировать реальную доставку. При отсутствии API посетитель видит честное сообщение, что заявка не отправлена, и номер телефона.
2. **Утвердить правовые документы.** `privacy.html` специально сделан черновиком без вымышленных адресов и условий. Требуется реальная политика обработки персональных данных, механизм согласия, учёт сервиса аналитики, а также проверка норм закона о рекламе юридических услуг и банкротстве.
3. **Проверить факты:** название и реквизиты ООО, адрес, часы, номер телефона, актуальность рассрочки «от 2 500 ₽/мес.», гарантии/условия договоров, возможность работать по области.
4. **Подтвердить отзывы и разрешения.** Имена и суммы взяты с действующей версии сайта, без придуманных цитат. Для карточек с материалами клиентов нужны согласие на публикацию, подтверждение фактов и предпочтительно прямые видео/ссылки на судебные дела.
5. **Подставить официальный логотип и портрет.** Для портрета использована ссылка на изображение текущего Tilda CDN. При недоступности показывается локальная SVG-иллюстрация. Для автономной работы следует заменить внешний URL на локальный оригинал после получения исходных изображений из Tilda.
6. **Настроить производственные SEO/аналитику:** canonical для окончательно выбранного домена, favicon, robots/sitemap, счётчики Яндекс Метрики и согласие на обработку cookies там, где это необходимо, call-tracking/события отправки форм и аналитика воронки.
7. **Проверить в продакшне** скорость загрузки, SSL, мобильную верстку, реальные звонки и отправку лидов. По исходному домену `.online` в процессе проверки были проблемы с HTTPS, тогда как `.ru` открывался.

## Как открыть

Дважды кликнуть `index.html` (файлы оставьте вместе), либо выполнить в папке сайта `python -m http.server 8000` и открыть `http://localhost:8000/`.

## Передача формы на API

Пример JSON:
```json
{
  "source": "quiz",
  "name": "Анна",
  "phone": "+79991234567",
  "consent": true,
  "quiz": {"Какая общая сумма ваших долгов?": ["500 000–1 000 000 ₽"]},
  "page": "https://example.ru/",
  "createdAt": "2026-11-09T12:00:00.000Z"
}
```
Сервер должен подтверждать успешное получение HTTP-кодом `2xx`. **Нельзя подключать публичный небезопасный webhook с секретами внутри HTML**; использовать защищённую серверную прокладку и защиту от автоматических заявок.

## Что ещё улучшит конверсию

Самый сильный следующий этап — публикация настоящих подтверждённых кейсов с номерами дел, видеороликов и карточек реальных сотрудников с именами/фото (если эти материалы есть). Не стоит добавлять вымышленные числа об успешности и неподтверждённые рейтинги.
